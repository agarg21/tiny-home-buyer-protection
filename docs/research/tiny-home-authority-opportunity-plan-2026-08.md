## Qualification Method

An opportunity is retained only when all of these are true:

1. Its current public page serves a materially overlapping audience.
2. A specific existing Tiny Home Clarity asset fills a visible resource gap.
3. A real editor, librarian, organization, or resource owner controls the page.
4. A current public contact or resource-suggestion path exists.
5. The path does not require payment, reciprocal links, membership, fabricated
   credentials, a mass template, or a new article written mainly for a link.
6. A short, transparent suggestion would still be useful if the recipient
   chose not to link.

Decisions use `pursue`, `hold`, or `reject`. `Pursue` means only that a separate
reviewed action may prepare and, after a human gate, send a bounded suggestion.
It is not permission to contact anyone in this action.
